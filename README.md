# Cat Web

Небольшой статический сайт о породах кошек.

## Страницы

- `index.html` - главная страница с общей информацией о кошках.
- `cat1.html` - страница об ориентальной кошке.
- `cat2.html` - страница о манчкине.
- `cat3.html` - страница о мейн-куне.
- `404.html` - страница ошибки.

## Технологии

- HTML5
- CSS3
